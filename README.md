# vcamera
This is a high-level interface for external developers. It encapsulates Camport3 and Camport4 underneath, and provides unified abstraction and adaptation for multiple firmware versions, different hardware capabilities, and cross-platform differences, effectively hiding complex underlying implementation details. The interface is simple, intuitive, and highly integrated, allowing developers to quickly complete device discovery, connection management, parameter configuration, data acquisition, and feature control through a consistent API without needing to understand low-level protocols or version differences. At the same time, it offers strong cross-platform compatibility and supports multiple programming languages, including C++, C#, and Python, meeting the needs of rapid integration, feature extension, and secondary development across different system environments and application scenarios.
